# whatsapp_group


Este proyecto presenta un análisis exploratorio de datos aplicado a conversaciones de WhatsApp dentro de un grupo de trabajo referente al desarrollo de un sistema de captura de información.

Este análisis se realiza con el objetivo de identificar patrones de comunicación, participación e interacción entre los integrantes de un grupo. El análisis incluye el procesamiento y anonimización de los mensajes, métricas de actividad por participante, comportamiento temporal, uso de archivos multimedia, menciones y análisis de contenido mediante técnicas básicas de procesamiento de lenguaje natural (NLP), como lematización y frecuencia de palabras. 

Adicionalmente, se exploran indicadores derivados del lenguaje, como el uso de expresiones de cortesía. Los resultados se presentan mediante visualizaciones estáticas desarrolladas principalmente con Pandas, spaCy, Seaborn y Matplotlib, facilitando la reproducción y consulta del análisis directamente desde el repositorio.
